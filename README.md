# Simple Interest Calculator

A simple interest calculator that calculates the interest earned on a principal amount over a specified period.

## Description
This project calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- **Principal (P):** Initial amount of money.
- **Rate (R):** Annual interest rate in percentage.
- **Time (T):** Time period in years.

## Output
- **Simple Interest:** Calculated interest amount.

## Example
- Principal: 1000
- Rate: 5%
- Time: 2 years
- Simple Interest: 100
